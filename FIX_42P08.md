# Исправление ошибки PostgreSQL 42P08

Исправлен `LedgerService.cs`:

- nullable-параметр квартиры теперь передаётся в Npgsql с явным типом `integer`;
- в SQL дополнительно используется `CAST(@apartment AS integer)`;
- nullable `id` передаётся с явным типом `bigint`;
- строковые/NULL параметры в общем helper теперь имеют явный тип.

Это устраняет `42P08: could not determine data type of parameter $1` на страницах Сальдо, Начисления и Платежи, а также предотвращает аналогичную ошибку при редактировании.

## Запуск

```bash
docker compose down -v
docker compose up -d
dotnet restore
dotnet run
```

Приложение: `http://localhost:5080`
