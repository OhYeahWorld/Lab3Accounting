# Исправление сборки

В исходной версии `_ViewImports.cshtml` и `_ViewStart.cshtml` находились в `Views/Shared`.
Razor MVC применяет эти файлы иерархически к представлениям внутри их каталога, поэтому страницы `Home`, `Ledger` и `Reports` не видели модели и layout.

В исправленной версии оба файла находятся непосредственно в `Views/`. Дополнительно в `@model` указаны полные имена типов.


### Исправление от 2026-10-02

- Удалена несовместимая с ASP.NET Core 8 настройка `устаревшую настройку MVC для value types`, из-за которой проект не собирался.
- Убрано фиксированное имя контейнера PostgreSQL, чтобы старый контейнер `lab3-postgres` не блокировал `docker compose up`.
- Host-порт PostgreSQL изменён с `5433` на `55432`; строка подключения приложения синхронизирована.
- Убраны nullable warnings в суммировании начислений/платежей.


## Дополнение: входящее сальдо в оборотной ведомости
В каждой месячной ячейке оборотной ведомости теперь выводятся четыре значения: входящее сальдо, начисления, платежи и исходящее сальдо.
